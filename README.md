# hxwl-01 新生儿听力筛查追踪台

把纸单随访改造为可追踪的工作台：初筛登记、42 天复筛任务、联系/延期留痕、号源互斥与跨店转档。

## 技术栈

React + Vite + TypeScript + CSS（不新增任何依赖，数据保存在浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

规则层冒烟测试（无需新增依赖，使用 vite 自带的 esbuild 打包）：

```bash
npm run test:rules
```

## 分层结构

代码按「筛查资料 / 判定规则 / 保存」三层分离：

- `src/screening/types.ts` — 筛查资料：数据模型（婴儿、双耳结果、检测方式、任务、号源、联系与延期、转档）
- `src/screening/rules.ts` — 判定与保存动作（纯函数，不依赖 React 与存储）：
  - 双耳均通过才结束随访；任一侧未通过按出生第 42 天生成复筛任务
  - 复筛双耳通过结束随访；单耳未过继续随访；双耳未过转诊断
  - 复筛室同一时段只接一名婴儿（号源占用校验排除已关闭/已确认转档任务）
  - 改期先释放原位置，再占用新位置，释放的号源与延期原因一并记入延期记录
  - 联系未果必须记录尝试与延期原因，应到日顺延
  - 转档待确认期间原门店任务不关闭、号源不释放；确认后才关闭移交，驳回继续本店随访
- `src/screening/storage.ts` — 保存层：localStorage 读写
- `src/screening/sampleData.ts` — 演示数据，全部经规则函数生成

## 主要功能

- 初筛登记：出生日期、初筛日期、门店、监护人电话、左右耳结果（通过/未通过/未检测）与检测方式（OAE / AABR），登记时实时预览判定
- 指标看板与状态筛选：随访中、逾期、临期、联系未果、已约、转档待确认、转诊断、已结束
- 任务详情时间线：初筛、每次联系尝试、延期、改期释放记录、复筛、转档状态
- 预约/改期：号源格子直观展示占用，改期强制填延期原因
- 复筛登记：双耳结果 + 统一检测方式，自动判定是否关闭随访
