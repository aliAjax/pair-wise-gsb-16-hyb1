# hxwl-01 新生儿听力筛查追踪台

替代纸单的初筛登记与复筛随访工作台：单耳未过不漏复筛，外地转档不重复安排。

## 技术栈

React + Vite + TypeScript + CSS（无新增依赖；数据保存在浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 业务规则

- **双耳通过才结束随访**：初筛任一侧未过，自动按出生第 42 天生成首轮复筛任务；复筛仍有耳未过，按复筛日 +7 天生成下一轮。
- **复筛室互斥**：同一门店同一时段全系统只接一名婴儿，时段格被占用即置灰并显示占位编号。
- **改期先释放**：改期先在占用视图中释放原位置再占新位置；新位置冲突则整体回滚，原预约保留；预约/释放/到筛均有流水。
- **联系留痕**：未接通、稍后再定、拒绝/暂缓等联系未果情况，必须登记尝试记录与延期原因。
- **转档两段确认**：申请后原门店任务锁定、已预约时段保留（防两地重复安排）；对方确认后才关闭任务并释放时段，驳回则恢复随访、预约原样保留。

## 分层（资料 / 判定 / 保存分离）

- `src/screening/types.ts` — 筛查资料的领域模型
- `src/screening/data.ts` — 演示纸单数据
- `src/screening/rules.ts` — 纯函数判定与流转规则（不碰 DOM / 存储）
- `src/screening/storage.ts` — localStorage 读写
- `src/components/`、`src/App.tsx` — 视图编排，只调用规则并统一保存
